# Boom Chat Room

Aplikasi chat WebSocket sederhana siap deploy ke Render.

## Deploy ke Render
1. Upload folder ini ke GitHub.
2. Buka Render Dashboard -> **New Web Service**.
3. Sambungkan repo GitHub ini.
4. Setting:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start` atau `node server.js`
